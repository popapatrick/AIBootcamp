# Spec Delta

## Purpose
Rețeaua de start e marcată ca reală, cu acuratețe mare; tot ce adaugă sistemul e marcat ca generat de model.

## ADDED Requirements

### Requirement: Rețeaua de start e reală și cu acuratețe mare
The system SHALL mark every element of the start network with origin `retea_start` and an initial score taken from `scor.initial_retea_start`.

#### Scenario: Element din KMZ
- **WHEN** modelul se încarcă
- **THEN** fiecare nod și tronson are `origine: retea_start` și scorul inițial din configurație

### Requirement: Puncte simulate hardcodate în rețeaua de start
The system SHALL load the pre-generated simulation points from a versioned file and treat them as part of the start network.

#### Scenario: Încărcare
- **WHEN** modelul se încarcă
- **THEN** punctele din `puncte-simulare.json` sunt în rețea cu `origine: retea_start` și nu se regenerează la rulare

#### Scenario: Fără suprapuneri
- **WHEN** se generează punctele
- **THEN** niciun punct nu e la mai puțin de distanța nodului nou față de un nod existent și toate sunt în zona prototipului

### Requirement: Punctele sistemului sunt generate de model
The system SHALL mark every element added by the system, including predictions, racordare chains and proposed routes, with origin `generat_model`.

#### Scenario: Predicție
- **WHEN** motorul propune un stâlp nou
- **THEN** elementul are `origine: generat_model` și UI-ul nu îl numește „Predicție AI"

#### Scenario: Confirmare de om
- **WHEN** un om acceptă predicția
- **THEN** elementul păstrează `origine: generat_model` și primește `confirmat_de: om`

### Requirement: Etichetă onestă pentru AI
The system SHALL use AI labels only for standardization (extraction, geocoding) and SHALL label predictions as generated by the model.

#### Scenario: Etichete
- **WHEN** UI-ul afișează un element
- **THEN** metoda de extracție e „AI (live)", „AI (cache)" sau „Regex (simplificat)", iar originea e „Rețea de start" sau „Generat de model"
